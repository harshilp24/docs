## Feature overview

Multi Tab Workspace lets you move between a task, a file or document, another task and a Friday chat without leaving your window or losing your place. Your context stays in one place, so the things you are working with stay in view instead of being something you navigate away to find.

The workspace splits your screen into two columns. Each column holds one or more tabs, and each tab can be a task, a Studio file or a Friday chat session. Every tab you open stays active, so you can switch between them at any time. When you step away and come back, your tabs are still open and loaded.

Multi Tab Workspace is part of Tasket and is available to all Tasket users in an organization.

## When to use Multi Tab Workspace

**Work on a task with Friday next to it.** A developer is working through a task and wants to ask Friday questions as they go. They keep the task in one column and a Friday chat session in the other, so both stay in view while they work.

**Cross-check two tasks.** A project manager is updating a task and needs to confirm details in a related one. They open the second task in the other column and keep both on screen while they write the update.

**Pick up where you left off.** A team lead is partway through a review when a message sends them to a different task. After dealing with it, they return to the original task and find their tabs open and loaded as they left them.

## How to use Multi Tab Workspace

### Understand the layout

The workspace has two columns. Each column has its own row of tabs along the top, with a **\+** button for adding another tab. A task tab shows the task code and title, and the tab you are viewing in each column is highlighted.

### Open a file from a task's comments

When a comment on the task you are reading mentions a file, select the file to open it as a new tab in the same window. The task stays open in its own tab, so you can read the file and return to the discussion without navigating away.

### Add a tab yourself

1. In the column where you want the new tab, select **\+**. A **New tab** opens.
2. Choose what to open: **Tasket** for a task, **Friday** for a chat session, or **Studio** for a file.
3. Pick the item. For a task, search by title or select one from the **Recent** list.

### Switch between tabs

Select any tab label to bring that tab forward. All open tabs, in both columns, stay active, so you can move between them whenever you need to.

### Return to your workspace

Your tabs work like a desk you leave set up. If you select a different task in the left navigation and later return to the task you were working in, the tabs you opened are still open and loaded.

### Make more room to read

Each tab can be expanded so you can give it your full attention. For a better view of the workspace, you can also collapse the left navigation using the collapse icon at the top of the left navigation panel.

### Close a tab

To close a tab, select its close icon (×). Closing a tab removes it from the column. It does not delete the task or file the tab was showing.

## FAQ

**How is Multi Tab Workspace different from opening Tasket in more than one browser window?**

Multi Tab Workspace brings tasks, Studio files and Friday chats into one Tasket window with a single left navigation. You keep related items in view without managing separate windows.

**Can I show a task and a Studio file side by side?**

Yes. Each column can hold a task, a Studio file or a Friday chat session, so you can put a task in one column and a file in the other. You can also put two tasks in separate columns.

**Do I have to open every tab myself?**

No. Files mentioned in a task's comments open as a tab when you select them. For anything else, add a tab yourself with the **\+** button in the column you want.

## Troubleshooting

**An Excel file opened in a new window instead of a tab**

Excel files open in a new window rather than as a tab in your workspace. This is expected behavior. Use the new window for the spreadsheet, then return to the Tasket window to continue with your tabs.

**The columns feel too cramped to read**

The screen is shared between the left navigation and the two columns. Expand the tab you want to focus on, or collapse the left navigation to free up room.

**My tabs seem to be missing after I selected another task**

Selecting a different task in the left navigation changes the task you are viewing, but it does not close the tabs you opened. Select the task you were working in from the left navigation to return to them, open and loaded.
