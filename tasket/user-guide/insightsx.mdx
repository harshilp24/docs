## Feature overview

Insights helps you see what's happening in your work and share it with the people who need to know. Describe the report you want in plain language, and an agent builds it. Then turn your reports into dashboards you can open whenever you need them, and share a dashboard with specific people or your whole organization.

Insights has two tabs. **Dashboards** lists the dashboards that already exist and opens them in a read-only view, where you can also ask an AI chat questions about the dashboard. **Creator** is where you build new ones. In Creator, you work in two stages: in a workbook, you create reports and chart them, and in Dashboard Builder, you arrange those charts, along with controls and layout elements, into a dashboard. You can create reports in three ways: with AI chat, with a semantic SQL query, or by pointing and clicking.

A dashboard shows each person the data they have access to. When a colleague opens a dashboard you built, they see the data they have access to, not what you can see. This means you can build a dashboard once and share it with many people.

You open Insights from the **...** menu on the top navigation when Tasket is the selected product. It opens in a new browser tab. Every user can create dashboards and reports from the Creator tab.

## When to use Insights

**Keep track of work across several projects**

A project manager runs multiple projects and wants one place that shows all their open tasks and their status. In Creator, they ask the AI chat to "Show me open tasks by status for each of my projects." They turn the result into a chart, put it on a dashboard, and open that dashboard whenever they want the full picture, instead of checking each project separately.

**Give your whole team the same report**

A team lead wants everyone on their team to look at the same open-task report. They build the dashboard once and share it with their team. Each person opens it and sees the tasks in the projects they have access to, so the lead doesn't need to build or send a separate report for each person.

**Follow what's happening in a sprint**

A sprint owner wants to know which tasks are in a sprint and how they are progressing. They build a report on sprint tasks and their status, chart it, and add it to a dashboard that they and others can open as the sprint goes on.

## How to use Insights

### Open Insights

1. With Tasket selected as the product, open the **...** menu on the top navigation.
2. Select **Insights**.

Insights opens in a new browser tab. The **Dashboards** tab opens by default.

### View a dashboard

1. In the **Dashboards** tab, find the dashboard you want in the left navigation.
2. Select the dashboard to open it.

Dashboards open in a read-only view. You see the data you have access to.

### Ask questions about a dashboard

1. With a dashboard open, select the chat icon in the bottom right corner.
2. Ask your question about the dashboard.

The chat answers from the data you have access to. It is read-only, so it can't change the dashboard. You can start a new chat at any time.

### Build reports and dashboards

You can create a report in three ways:

- **AI chat** is the easiest. You describe the report you want in plain language.
- **Semantic SQL** is the next step up. You write the query yourself.
- **Point and click** has you choose the fields and the chart yourself, step by step.

You can mix them. For example, you can start with the AI chat, then refine the result by pointing and clicking or in SQL mode.

Whichever way you create the reports, you then arrange them into a dashboard in Dashboard Builder, publish it, and share it.

#### Start a workbook

1. Open the **Creator** tab. It lists the folders and workbooks your team has created.
2. Create a folder, or create a workbook directly.

When you create a workbook, you land on a page with two options: **Workbook** and **Dashboard Builder**. **Workbook** opens by default. Use **Workbook** to decide what data to show and how to chart it. Use **Dashboard Builder** to decide how the charts are laid out on the dashboard.

#### Option 1: Build with AI

When you create a workbook, the AI chat opens as a side pane. You can also open it with the AI agent button below the default views.

1. In the chat, describe the report you want, for example "Show me open tasks by status for each of my projects."
2. The chat creates a workbook tab with a chart.
3. Save and publish the report. You can ask the chat to do this, or use the **Publish** icon on the right.

If you ask for a completely different report in the same chat, the chat creates a new workbook tab for it, and you need to switch to that tab to see it. Use the tabs on the bottom navigation bar.

You can use the same chat in **Dashboard Builder**. It opens in the right pane and can add widgets, edit widgets, add containers, and do the other things described in "Arrange the dashboard" below. You can also ask it to save and publish your work.

#### Option 2: Build with a semantic SQL query

Use the semantic SQL option at the bottom of the screen to write your query.

#### Option 3: Build by pointing and clicking

1. Select one of the existing views. The editor opens with folders and predefined items in the left navigation. You can search the folders and items.
2. Choose fields from them to build a table.
3. To create a pivot, choose the pivot option from the options available for the folders and items in the left navigation.
4. After you choose fields, you can switch between results, charts, and SQL mode.
5. Open the charts section and choose how to show your report, such as a bar chart, a pie chart, or a table.
6. Select the **Publish** icon on the right to publish your changes.

Two controls change how the report runs:

- **Order and limits**, in the top right corner, lets you define the order and the limit.
- You can turn auto-run for the report on or off.

#### Work with workbook tabs

A workbook can have more than one workbook tab. Each workbook tab holds its own report, and each can become a widget on a dashboard. Create a new workbook tab for each report you want to show.

#### Arrange the dashboard

After you publish, switch to **Dashboard Builder**. It has four options for adding widgets:

- **Charts**: add a chart and select the workbook tab it should show.
- **Add controls**: add Time Granularity, Filter, Field Switcher, or Parent controls.
- **Add Containers**: arrange your view with horizontal stacks, vertical stacks, tabs, or a grid.
- **Add Other Widgets**: add space, text, or a divider.

The settings option in the top right corner covers themes, time zones, and **Prevent collision**, among other features. When **Prevent collision** is on, widgets can't be moved on top of each other.

#### Share the dashboard

Publish your changes, then share the dashboard with people by adding their alias. You can also share it with the whole organization.

### Edit a dashboard

Only the person who created a dashboard can edit it.

1. Open **Creator** and open your dashboard.
2. Select **Edit** in the top right corner. You land on the views you created.
3. Open the AI chat in the right pane and describe your changes.

### Manage workbooks

You can rename, duplicate, or delete a workbook. You can also edit it after you create it.

Deleting a workbook also deletes its dashboards and reports.

## FAQ

**Which data can I report on?**

You choose from the views available in a workbook. They cover data from Tasket tasks that you have access to.

**Can I change a dashboard from the Dashboards tab?**

No. Dashboards open in a read-only view there, and the chat there can't change them. Only the person who created a dashboard can edit it, in the **Creator** tab.

## Troubleshooting

**A dashboard shows different data from what its creator sees**

A dashboard shows each person the data they have access to. If your access differs from the creator's, you will see different data. This is expected.

**The report I asked the chat for doesn't appear**

The chat creates a new workbook tab for each different report you ask for. Check the tabs on the bottom navigation bar, towards the left, and switch to the new one.

**I can't find the report I want when I add a chart in Dashboard Builder**

Charts in Dashboard Builder are built from workbook tabs. Go back to **Workbook**, create a workbook tab for the report, then return to Dashboard Builder and add the chart again.

**The chat on a dashboard didn't change the dashboard**

The chat on the **Dashboards** tab is read-only and can only answer questions. To change a dashboard, its creator can edit it in **Creator**.
